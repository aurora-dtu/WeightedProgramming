2. Preliminaries🔗

Much of the foundational structures and theories we use, we can inherit from mathlib, which we attempt to do as much as possible. However, some of these are slightly different from the requirements we have, which we will make clear as necessary.

Definition 2.1, which introduces monoids, are present in mathlib under Monoid (where the operator is * and unit is 1) and AddMonoid (where the operator is + and unit is 0). They each have commutative variants CommMonoid and AddCommMonoid, of which we will use the latter more often.

Definition 2.4 introduces modules, which in mathlib terms is a MonoidWithZero with a AddCommMonoid.

variable {𝒲 ℛ : Type} [MonoidWithZero 𝒲] [AddCommMonoid ℛ]

The scalar multiplication joining the two are given by SMul and it's associative, distributive, annihalation and neutrality properties are given by DistribMulAction.

The below definition is extracted from the lean source code. Click the checkbox next to MulAction under Extends to see the full definition.

🔗type class
DistribMulAction.{u_12, u_13} (M : Type u_12) (A : Type u_13) [Monoid M]
  [AddMonoid A] : Type (max u_12 u_13)
DistribMulAction.{u_12, u_13}
  (M : Type u_12) (A : Type u_13)
  [Monoid M] [AddMonoid A] :
  Type (max u_12 u_13)

Typeclass for multiplicative actions on additive structures.

For example, if G is a group (with group law written as multiplication) and A is an abelian group (with group law written as addition), then to give A a G-module structure (for example, to use the theory of group cohomology) is to say [DistribMulAction G A]. Note in that we do not use the Module typeclass for G-modules, as the Module typeclass is for modules over a ring rather than a group.

Mathematically, DistribMulAction G A is equivalent to giving A the structure of a ℤ[G]-module.

Note that we are not using Module from mathlib, as that would require 𝒲 to be a Semiring, which we do not require, while DistribMulAction has exactly the properties we want.

We consider only structures ℛ with orders being CompleteLattice's, which provide sSup and sInf as supremum and infimum over sets. Definition 2.6 defines naturally ordered captured by CanonicallyOrderedAdd.

variable [CompleteLattice ℛ] [CanonicallyOrderedAdd ℛ]

Definition 2.8 defines ω-continuity which we formalize as two type classes ωScottContinuousAdd and ωScottContinuousSMul. These build on the notion of ωScottContinuous from the OmegaCompletePartialOrder module (a weaker order than CompleteLattice and this we have an instance OmegaCompletePartialOrder ℛ). This bears a connection to continuity in the Scott topology Topology.scott, but the only property we rely on is preservation of ωSup, the chain/countable analogue of iSup.

Lemma 2.9 introduces countable sums. There is not, at the time of writing, a direct correspondence to this notion of a countable sum defined for CompleteLattice's with AddCommMonoid and CanonicallyOrderedAdd. The closest is tsum, short for topological sum and defined as a topological limit. However, since we do not impose a topological space on our structure, we use an alternative definition based on ωSup namely ωSum, heavily inspired by Weighted NetKAT's  (Acevedo et al., 2026)Emmanuel Suárez Acevedo, Tiago Ferreira, Kevin Batz, Oliver Bøving, Nate Foster, and Alexandra Silva, 2026. “Weighted NetKAT: A Programming Language for Quantitative Network Verification”. In PLDI. definition under the same name.

🔗def
OmegaCompletePartialOrder.ωSum.{u_1, u_3} {ι : Type u_1} {α : Type u_3}
  [Countable ι] [OmegaCompletePartialOrder α] [AddCommMonoid α]
  [AddLeftMono α] [IsBotZeroClass α] (f : ι → α) : α
OmegaCompletePartialOrder.ωSum.{u_1, u_3}
  {ι : Type u_1} {α : Type u_3}
  [Countable ι]
  [OmegaCompletePartialOrder α]
  [AddCommMonoid α] [AddLeftMono α]
  [IsBotZeroClass α] (f : ι → α) : α

ω∑ i, f i is the countable sum of f defined as the ω-supremum over sums finite subsets.

Note that ωSum is defined for Countable ι : Prop while Finset.ωSup is for Encodable ι : Type. Since the sum is exhaustive, the instance of Encodable is irrelevant and thus use Encodable.ofCountable ι.
